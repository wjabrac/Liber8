# LIBR8 Repository Map

## Major Modules
- `src/cognition/`: Canonical cognition engine, persistent event loops, and backend configurations. Driver of thought and memory.
- `src/service/`: Service and HTTP API wrapper, application lifecycle (e.g. `app.py`, `http.py`), and operational state-store contracts.
- `src/contracts/`: Defines internal and external schemas, validation rules, state serialization, and schema migrations.
- `src/failures/`: Failure classification, retry policies, and error taxonomies.
- `src/tools/`: Tool execution gateway, registry, and policy controls (e.g. MCP integration).
- `src/ops/`: Operational logging helpers, run retention, and garbage collection.
- `src/retrieval/`: Handles document/snippet retrieval and ranking for cognition context.
- `src/replay/`: Run aggregation and tracing for evaluations.
- `src/cli.py`: Native command line interface endpoints (`run`, `healthcheck`, `serve`).
- `tests/`: Smoke, architecture, unit and end-to-end integration tests.

## Key Entrypoints
1. **CLI**: `src/cli.py` (exposed directly or via `main.py` when properly passing `sys.argv`). Provides `healthcheck`, `serve`, `run` subcommands.
2. **Service / API**: Wrapped around `src.service.app`, instantiated using `python src/cli.py serve`.
3. **Test Suite**: Run using python's built-in `unittest` module (`python -m unittest discover tests`).
